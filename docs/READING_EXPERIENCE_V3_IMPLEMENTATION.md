# 阅读体验 V3：实施与验收

本轮范围：按用户确认的顺序实现性能／交互、排版、外部字体、撤销／自动备份、
跨段批注及 macOS 听书；补齐书架分组／状态、配色／简繁显示、离线跨书搜索、
笔记批量操作和下载反馈。不加入云同步、多窗口、AI 剧情。此前不自动提交／
推送的决定，已由用户 2026-11-07 的自用云端打包授权替代；版本不递增，
不改写 Android 正式发布，见 [自用打包说明](MACOS_INTERNAL_RELEASE.md)。

## 顺序与完成条件

1. 动画速度、点击翻页开关、快捷键配置、异步仿真快照；测量输入延迟与帧间隔。
2. 中文标点／孤行、栏间距／行宽、颜色／简繁；保留原文坐标。
3. TTF／OTF 校验、预览、导入／删除与回退，全局／单书独立。
4. 撤销、回收站、自动备份保留策略；书架／搜索／笔记／下载改进。
5. 跨段／跨页范围、精确定位／歧义拒绝、旧版兼容、导出／备份往返。
6. 可用系统语音、OpenAI 兼容 TTS、Keychain、播放器／媒体控制、暂停／取消、
   迟到事件、跨章、定时停止、原文高亮与输出变化。

## 已实现的功能与边界

| 顺序 | 实现 | 使用入口 / 安全边界 |
|---|---|---|
| 1 | 动画速度、点击开关、有效快捷键重映射、异步仿真背面快照 | 阅读设置 → 高级；输入法 / 输入框 / 原文选区优先，系统编辑和退出组合保留。Profile 测量命令到提交帧和帧间隔，不冒充物理输入到屏幕延迟 |
| 2 | 中文分页标点和孤行退避；栏距、字号相关行宽；自定义 HEX 和对比度提示；简繁显示 | 不挤入超出容量的字，不切断字素；简繁离线一对一 UTF-16 字符映射，多义字不保证语义正确；正文原文、复制、查询、批注和 TTS 不改写 |
| 3 | TTF / OTF 结构、长度、表边界和 SHA-256 校验；预览、去重、导入和删除；字体回退 | 最多 20 个 / 200 MB，单个 20 MB；不安装系统字体、不删除原文件。字体缺失不改写偏好或原文坐标。手动备份可含字体，自动快照仅保存字体索引 |
| 4 | 笔记修改 / 删除、书签和书架移除先复制旧版本；撤销和回收站；应用内自动快照 | 回收站 30 天 / 1000 次 / 16 MB，满或损坏时拒绝新破坏操作；撤销拒绝覆盖后续版本。自动快照默认关闭、6–168 小时间隔 / 3–30 份 / 128 MB，先验证新份再清理旧份，不能替代外部备份 |
| 4+ | 分组 / 阅读状态 / 书架搜索；离线跨书正文搜索；笔记预览 / 批量标签 / 状态记忆；正文全部匹配高亮；下载顺序、并行与错误详情 | 搜索和原文预览不联网，缺目录不猜章节顺序；结果重新核对引用再开缓存正文。标签加到现有标签上。队列默认 2 本 / 12 章，可调 1–4 本 / 3、6、12 章；只对明确网络异常做最多 2 次退避，访问 / 文件错误手工重试 |
| 5 | 同章连续范围跨段 / 双栏 / 可见分页批注；V3 起止段落与 UTF-16；逐段渲染、唯一引用重定位 | 最大 20000 字符；跨章或未选完整中间原文仅复制，不伪造范围。单段仍是版本 2；编辑、导出和备份不丢掉终止段落 |
| 6 | AVSpeechSynthesizer / 可用声音选择；AVAudioPlayer MP3、WAV；Keychain；媒体命令；跨章 / 定时 / 停止 / 焦点与输出变化；原文高亮 | 阅读菜单及播放器发音设置；无系统声音明确提示。网络失败的系统回退明确显示，不跳正文。播放器不再把服务的 `speed` 应用第二次；暂停系统语音从本段重新开始；离开阅读页可继续播，不承诺合盖 / 系统睡眠期间播放 |

原生输出变化会暂停，但 macOS 没有 Android 的前台服务与音频焦点模型；
不模拟不存在的系统能力。渐弱对网络音频实时生效，系统语音的实时音量变化受
AVSpeechSynthesizer 限制，截止时间仍执行停止。

已修复原生联调发现的设置关闭动画错误：弹窗 Future 在 pop 时完成，而控制器必须
等实际 widget unmount 才释放。发音设置、分组名及批量标签使用正确的资源所有权。

## 协议依据

已读取 official OpenAI documentation：
https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create/

沿用 Android 的 `model / input / voice / response_format / speed` 与自定义
Base URL，不替换用户模型。官方模型的弃用计划不代表其他兼容服务；
无凭据时仅用隔离本地服务测协议，不发送用户小说或密钥。

- 接口接受根 Base URL、带 `/v1` 的 Base URL 或完整 `/audio/speech` 路径；
  HTTPS，仅本机开发地址允许 HTTP；拒绝 URL 账号、查询密钥和片段。
- 请求仍是 `model / input / voice / response_format: mp3 / speed`，模型和音色
  任意可配置，不假设厂商实现全部官方模型；模型弃用计划不自动覆盖用户配置。
- 响应有整体期限、16 MB 大小限制、音频结构检查和原生解码检查；
  401 / 403 不重试，重定向不转发 Bearer，429 / 5xx 最多再试一次。
- 设置主体作为无密钥 JSON 原子写入，保留安卓旧键的兼容镜像；密钥走
  既有 `readTtsSecret / writeTtsSecret` 合约，macOS 是 Keychain、Android 是
  原安全存储，不自动复制或导出另一设备密钥。
- 只删除本服务实际创建的临时音频，不把任意路径当清理目标。
