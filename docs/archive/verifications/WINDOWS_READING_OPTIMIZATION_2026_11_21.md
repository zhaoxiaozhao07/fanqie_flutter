# Windows 阅读定向优化与验证

日期：2026-11-21。工作分支：`feat/windows-client`，起始 HEAD `251b54e`。

本轮在原工作区增量修改，保留已有未提交的 Windows、选择、听书及平台桥接改动；未提交、推送、整文件覆盖合并或改变发行版本号。主线 `7b05cb6` 的下载优化按功能兼容移植，补齐审查发现的可靠性问题。

## 阅读体验

- 同一翻页引擎内保留 PageController；使用稳定页身份和子项索引，使相邻章节进入/离开缓存时不重新挂载当前页。
- 仿真翻页以页身份保留相邻页面和纸背快照；保留旧调用方式、字素坐标、选择与取消行为。
- Windows 连续大幅滚轮信号可继续翻页；小幅惯性、反向抖动、正文选择和内层滚动保留优先级。翻页提交和异步换章保留最新输入来源，不能重放过期请求或重复请求尚未就绪章节。
- 页边提供即时鼠标翻页入口，位于原有左右留白内，不侵占正文。正文单击仍保留双击选词等待，这是有意的选择保护；使用页边或键盘无需该等待。
- 自定义背景、正文、次要色和高亮色使绘制缓存失效，但不重新测量分页；暗色桌面工具栏、全屏章节标识使用阅读主题。
- 超长段落只测量有界、字素完整的文本窗口，按需扩大；不反复测量/复制整段剩余文字。保留 emoji、组合字符、图片块、章节结尾和宽页面填充。

## 下载与原生可靠性

- 离线/临时缓存优先完成，按完整成功章节记录进度，有界补漏；EPUB ZIP 压缩移至工作 isolate，首项 mimetype 不压缩。
- 插图校验实际字节；损坏的受保护 UTF-8 副本保留隔离副本，再原子修复；不能仅根据文件存在判完整。
- 下载身份只使用属于 bookId 的记录路径/URI。URI 校验不可用时失败关闭，不借同名或显示路径误判。
- 请求截止时间覆盖连接、响应头和正文，限制响应体大小。密钥恢复绑定原设备，重试计入预留额度，释放额度不能永久丢弃仍可复用的会话；注册故障使用有界冷却。
- Android 导出不前置删除旧同名文件；完成发布后可选名称查询失败不回滚已完成文件。无可靠物理路径时返回权威 URI。
- Windows 保存对话框使用独立 COM STA，取消锁存与自身窗口关闭支持创建中/排队/显示中取消。结果和队列仍在平台线程，保留原子复制及提交后成功语义。
- 复制线程启动失败保留完成回调，报告一次失败并释放队列，不让异常逃逸至窗口回调。

## 性能与尚未验证项

- AOT Profile 分项已观察到单栏五种效果及实际双栏的栅格 P95 约 1.8–3.8ms；部分采样起止窗口处于前台，但不等于全程前台或物理输入延迟。
- 完整七场景性能运行未完成：系统焦点/隐藏状态变化使前台获取超时或停止提交帧；保留失败记录，**不宣称完整前台性能验收通过**。
- 异步跨章性能 helper 改为同时等待实际页提交和空闲，不能把准备中的空闲误认为翻页完成。
- 真机原生显示倍率本轮为 1.0；2x DPI 属于自动化组件回归，更多物理 DPI/多显示器仍需实机验收。
- 手工成功另存为/确认覆盖往返、其他 Android MediaStore 设备/工作资料行为未实测；JVM 边界故障测试和 APK 编译不能替代设备认证。
- Android 工具链有未来支持提醒，本轮不做无关 Gradle/AGP/Kotlin 升级。
