## E1

- 增加版本化原文进度快照，单条记录作为续读权威来源，旧键仍作为兼容摘要。
- 跨阅读器实例按书串行写入，进度提交后再更新历史与书架。
- 所有续读入口按稳定章节 ID 恢复；详情页显式点章不被旧进度覆盖。
- 目录章节删除或 ID 变化时清除无效字符偏移，并提示降级定位。
- 保留现有字体、主题、模式切换保位机制。
- 新增 v1 迁移、损坏/未来版本、100 次串行保存、目录变化和显式开章测试。

## E2

- 独立临时阅读缓存目录，原子写入，按容量/LRU 清理；下载、本地导入和旧版离线资源不参与淘汰。
- 新增磁盘实际可读范围、临时缓存占用、清理确认、仅 Wi-Fi 和三档预取策略。
- 前台点章提升排队请求；跳章/退出清理过期任务；超时保留当前正文并提供重试。
- 滚动模式加载失败不再保留永久转圈；下载失败不再写入伪正文并报告成功。
- 短小的本地章节可以正常离线读取；本地书缺章不再请求远端内容。
- 评论先返回缓存、后台限频更新；评论 JSON 改为原子写入。
- 修复“下载后续章节”错误地包含当前章的边界。
- 新增缓存隔离、LRU、路径安全、原子并发写、网络策略、缓存优先评论和失败重试测试。
- 最近一次全量测试：124 项通过；最终发布前将再次全量验证。

## E3

- 播放会话、章节和切片采用独立代次与原生回调 token，异常暂停而非跳过正文。
- 书籍播放队列移至服务，离开阅读页面后继续播放；增加主页播控和后台进度保存。
- 网络缓冲可暂停，降级后按实际引擎恢复；分块保留原文范围，避免重复句子误定位。
- Android 增加缓存 FlutterEngine、前台媒体服务、MediaSession、音频焦点、耳机断开、定时停止。
- 原生语音先合成为应用临时音频再播放，使音量淡出不影响系统总音量。
- 密钥采用 Android Keystore AES-GCM；配置与备份不保存明文密钥。
- E3 阶段 Dart 全量测试 136 项通过；Android Debug APK 构建通过。
- 增加专用模拟器平台测试脚本，验证真正的原生音频、锁屏后台、媒体状态和安全存储。
- 首次 Gradle 下载截断；改用体积更小的同版本 binary distribution，并固定官方 SHA-256 校验。
- 修正 Flutter 全局 `android-sdk` 配置中错误的 platform-tools 路径，保留项目使用的完整 SDK。
- API 35 arm64 专用模拟器的 4 项平台测试全部通过：Keystore 往返、真实播放器暂停/恢复/音量与 token 隔离、缺少原生语音引擎时明确失败、关屏后台播放及系统媒体键暂停/继续。
- 关屏测试通过 Android `cmd media_session dispatch` 注入系统媒体按键；普通 `input keyevent` 在关屏模拟器上未投递，未放宽业务断言。
- 当前模拟器不带中文语音引擎；原生合成成功路径由自动化协议测试覆盖，中文发音质量与低端真机性能仍需真实设备验证，不宣称已验证听感或帧率指标。

## E4

- 已新增独立设置模型、版本化存储、单书覆盖、个人排版预设和新的设置面板。
- 完成设置面板接入、全局/单书切换、预设保存与恢复、手动/跟随系统/定时夜间。
- 各续读入口预先读取设置，首次进入夜间阅读不先绘制浅色背景。
- 窗口亮度仅在阅读作用域生效，弹层保留、离开阅读恢复；音量键和常亮也加入阅读器所有权管理。
- 主题颜色不再使分页缓存失效；次要文字移除过低透明度，五套配色的正文/次要文字/高亮文字对比度均通过 4.5:1 测试。
- 模拟器截图检查通过；修复 320dp 设备底部菜单横向溢出和夜间导航栏浅色问题。
- 扩展后的 5 项 Android 平台测试通过，包含弹层/页面切换亮度与初始夜间样式验证。
- 30 分钟关屏长时测试脚本已准备，用于继续验证音频缓存上限与后台进度。

## 长时验证

- 30 分钟关屏测试通过：连续真实原生音频播放、持久化原文位置推进、最多 4 个有效音频缓存、系统媒体暂停/继续。
- 使用本地合成测试音频验证管线和生命周期，不将其描述为中文语音听感测试。

## E5

- 本章/已缓存正文检索，不为搜索下载全书；支持大小写选项、取消、覆盖范围与结果上限说明。
- 关键词按原文范围定位，重复词句不会跳到第一处，emoji 高亮保留完整字素。
- 大章节在 isolate 检索；优先内存正文，缓存目录一次枚举，不逐章探测未缓存长目录。
- 目录、书签、笔记、原文定位与搜索共用显式跳转；增加有界返回栈与不会遮挡正文的返回栏。
- 等待中的跳转可取消，失败不写入返回栈；显式换位置停止当前书听书，避免语音将视图拉回。
- 修复目录弹层关闭动画期间过早释放输入控制器，以及远距离跳章后旧页面读取被淘汰段落缓存的问题。

## E6

- 新增文件选择、编码/分章规则和确认前预览；解析在临时目录/isolate 中完成，取消不发布半本书。
- TXT 流式处理，Android 流式 UTF-8/UTF-16/GB18030/Big5 转码；EPUB 按 OPF spine 和 nav/NCX 顺序解析。
- ZIP 目录与实际解压量均有限额，拒绝不安全路径、符号链接、加密正文和校验错误。
- 内容与配置摘要生成稳定书籍标识；安全匹配旧版书籍时保留旧 ID 与阅读数据，预览不修改旧书。
- 导入单元测试 11 项通过；扩展后的 7 项 Android 平台测试通过，包含 GB18030 中文/四字节 emoji 转码及大文件取消。
- 原文件保留、同名不同内容隔离、相同文件去重、旧版 ID 安全沿用、确认前不修改旧书均有回归覆盖。

## E7

- 增加顶部/底部状态开关、屏幕常亮开关、可选触感和默认关闭的非阻断休息提醒。
- 阅读页提供可访问的翻页语义操作；交互按钮补足标签与触摸尺寸，选词工具栏支持换行。
- 手动滚动/翻页停止本书听书，避免播放跟随抢回用户位置。
- 320dp、2 倍文字缩放的阅读菜单/设置回归通过；修复底栏信息溢出及语义树合并时的框架异常。

## E9

- 默认关闭的本地阅读统计，分开记录看书与听书；后台和超过 90 秒无交互的看书停留不累计。
- 主动跳章断开字数推进统计，不把跳过内容计为已读；统计可关闭/清空且不影响进度。
