# 🍅 番茄Reader 纯小说阅读功能增强实施文档 (Implementation Plan)

## 一、 规划背景与核心原则

本实施方案专为**纯粹小说阅读**场景定制，剔除无关的短剧、漫画、视频以及低频的内容搜索与水文过滤，全力聚焦在提升小说阅读过程中的**排版质感、翻页体验、离线顺畅度、沉浸辅助、书签笔记、书架追更以及听书体验**。

### 实施功能清单 (共 10 项)
1. **目录正序 / 倒序一键切换与分卷折叠收起**
2. **后续 3~5 章静默预加载流水线 (Silent Pre-fetching)**
3. **阅读排版定制与自定义字体支持 (首行缩进、字间距、段落间距、字体切换)**
4. **阅读器双模式支持：垂直连续滚屏 / 左右翻页模式 (水平分页滑动)**
5. **沉浸式自动阅读 / 自动平缓滚屏 (Auto-Scroll)**
6. **书签、划线高亮与阅读笔记系统 (长按标注、书签管理与抽屉速查)**
7. **连载书籍更新检测与书架红点提示 (Update Watcher)**
8. **本地 TXT / EPUB 小说导入与阅读支持 (纯本地图书解析并入书架)**
9. **听书定时“读完本章后自动停止”与平滑停止**
10. **听书锁屏媒体通知栏播控与后台交互协议**

---

## 二、 详细设计与实现方案

### 模块 1：目录体验与章节智能预加载
#### 1.1 目录正序 / 倒序与分卷折叠
+ 需求场景：动辄几千章的长篇小说，倒序方便立刻查看最新章节；支持番茄原版分卷折叠。
+ 实现方案：
  + 在阅读器目录弹窗顶部增加「正序 / 倒序」切换按钮与分卷折叠/展开开关；
  + 章节列表支持快速按分卷（Volume）分组与展开/折叠，倒序时自动倒转章节列表视图；
  + 切换正反序保持当前阅读章节平滑定位能力。

#### 1.2 后续 3~5 章静默预加载流水线
+ 需求场景：彻底解决网络波动导致滑到章尾出现 Loading 骨架屏的问题，做到断网零等待。
+ 实现方案：
  + 在 `ReaderScreen` 中引入 `_silentPreloadPipeline`；
  + 当阅读进入当前章节后半段（例如当前视口超过本章 50% 进度），后台静默触发拉取后 3 章（`index + 1`, `index + 2`, `index + 3`）的正文与段评数据；
  + 内部利用已有的 `isChapterOffline` 与磁盘持久化，不重复拉取已缓存章节，低优先级后台并发执行。

---

### 模块 2：阅读器排版质感与左右翻页模式
#### 2.1 排版定制与字体扩展
+ 实现方案：
  + 存储并支持用户配置：首行缩进（2 字符开关）、字间距（`letterSpacing` 0~3）、段落间距（`paragraphSpacing` 8~24）；
  + 字体配置：内置系统默认、楷体/宋体字体选项，并支持从外部存储选择 `.ttf` / `.otf` 字体文件；
  + 在阅读设置弹窗中直观呈现排版滑块与字体选择器，配置实时保存于 `SharedPreferences`。

#### 2.2 左右翻页模式（PageView 水平分页）
+ 实现方案：
  + 在设置面板中支持「连续滚屏」与「左右翻页」两种模式切换；
  + 翻页模式下使用 `PageView.builder`，按屏幕尺寸与当前字号/行距排版分页展示章节内容；
  + 支持左右点击热区翻页（左侧前翻、右侧后翻、中间唤起菜单），以及滑动翻页。

---

### 模块 3：沉浸式自动滚屏阅读 (Auto-Scroll)
+ 实现方案：
  + 在阅读器菜单栏新增「自动阅读」快捷入口；
  + 启动后以可调速度（例如 20~100 px/秒）使用 `Ticker` / `Timer` 平缓驱动 `_scrollController` 自动向下滚动；
  + 屏幕底部展示小巧的浮动控制条（调节滚动速度、暂停/继续、退出自动滚屏）；
  + 点击屏幕任意位置即刻暂停，保障读者随时介入交互。

---

### 模块 4：书签、划线高亮与阅读笔记系统
+ 实现方案：
  + 数据模型：新增 `Bookmark`（书签：书籍 ID、章节序号、章节名、段落偏移、创建时间）与 `ReadingNote`（划线笔记：段落文本、选中片段、读者批注、时间）；
  + 持久化：新增 `BookmarkService`，使用本地 JSON 文件或 SQLite 进行书籍级存取；
  + 交互：
    + 阅读器顶部快捷添加/取消当前位置书签；
    + 长按段落弹出操作气泡（高亮划线、写批注、复制）；
    + 目录弹窗旁边增加「书签与笔记」选项卡，支持列表展示并一键跳转定位。

---

### 模块 5：连载追更检测与书架更新红点 (Update Watcher)
+ 实现方案：
  + 在 `BookshelfService` 中增加追更状态检测接口 `checkBookUpdates()`；
  + 比对本地保存的最新章节与远端最新章节；
  + 书架页面支持下拉刷新触发检查，有更新的书籍在封面右上角展示「更新 N 章」徽标；
  + 点击直接进入最新章节或从最后阅读位置继续追更。

---

### 模块 6：本地 TXT / EPUB 小说导入与阅读
+ 实现方案：
  + 新增 `LocalBookService`，负责解析本地 `.txt` 与 `.epub` 文件；
  + TXT 智能章节切分：基于多级正则（`第[0-9一二三四五六七八九十百千万]+[章回节卷集]` 等）智能拆分为结构化章节；
  + EPUB 解析：提取其中的 `toc.ncx` / `nav.xhtml` 目录与 HTML 章节正文；
  + 生成虚拟 Book 对象加入书架与离线缓存，无缝复用现有阅读器、排版、书签与听书功能。

---

### 模块 7：听书进阶优化 (定时整章停止与锁屏媒体通知控制)
+ 实现方案：
  + 定时器增强：在 `TtsService` 中增加 `stopAfterCurrentChapter` 开关，当本章最后一个切片朗读完毕后自动安全停止，并具备结束前 10 秒音量淡出；
  + 媒体中心播控支持：在 `ReaderSystemService` 和 `TtsService` 中联动平台通道，发出播放元数据通知（书名、当前章节、状态），支持耳机线控双击切换与暂停/继续。
