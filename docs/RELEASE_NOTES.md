## v3.2.0 — 阅读体验增强

- **准确续读**：原文锚点、统一进度快照、目录变化提示，跳转后可返回原位置。
- **弱网离线**：预取策略、Wi-Fi 限制、缓存容量与实际可读范围；失败可重试，保留当前正文。
- **舒适排版**：个人预设、单书覆盖、独立窗口亮度、跟随系统/定时夜间主题。
- **正文搜索**：本章/本地缓存检索、范围说明和精确匹配定位，不自动下载全书。
- **听书闭环**：前台媒体服务、锁屏控制、焦点/耳机处理、会话隔离、跨章定时及有界音频缓存。
- **本地导入**：文件选择和确认前预览，中文编码支持，EPUB spine/nav/NCX 顺序，稳定身份与安全解析。
- **纯净与无障碍**：左右手操作、大字布局、语义翻页、可选触感与休息提醒。
- **批注与备份**：同章多书签、精确选区、颜色标签、编辑导出、本地合并/替换恢复与中断回滚。
- **阅读辅助**：默认关闭的本地统计、看书/听书分开记录、本章剩余时间估计和上次阅读片段。

### 数据与隐私

- 旧版阅读数据兼容迁移；能够安全匹配的旧本地书保留原 ID，不盲目覆盖同名书。
- 语音密钥使用 Android Keystore，不纳入阅读备份。
- 统计默认关闭，小说正文与笔记不会因统计而上传。网络语音仅在用户启用时发送到其配置的服务。

### 验证说明

发布门禁包含全部 Dart 测试、Android 平台回归、30 分钟关屏测试及签名 APK 构建。平台测试使用受控音频验证真实播放器与生命周期；不将其表述为所有中文引擎音质或所有真机性能验证。

输入 TXT/EPUB 最大 128 MB；不支持 DRM 加密正文。第三方接口可用性、设备语音包与厂商后台限制仍会影响体验。

下载 APK 后可使用随附 `.sha256` 文件核验完整性。
