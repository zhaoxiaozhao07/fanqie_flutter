## v3.3.0 — EPUB 插图与图片章节修复（构建 333）

- 修复 EPUB 导入只提取文字导致正文插图丢失：支持本地位图、SVG、SVG 包裹的位图和纯图片章节。
- 滚动及五种翻页模式按内容顺序显示图片，点击可缩放；损坏、缺失或不支持的图片保留提示。
- 图片独立于正文保存，不污染搜索、听书或批注偏移。旧 EPUB 重新导入同一原文件时可补齐插图，正文一致才升级，保留原书 ID、正文、章节 ID、进度、书签及笔记。
- 保留此前首页美化和阅读状态栏右下角定位。继续覆盖 `v3.3.0`，沿用原快速签名构建发布 workflow，无关屏实验门禁。

### 保留 v3.3.0 的能力

- **动态分类**：首页读取当前频道的官方分类名称、ID 与分组，支持查找、全部分类与已获取分类的离线缓存；不再写死 17 个分类。
- **准确筛选**：字数区间使用官方 `0–4` 参数；分页遵循 `has_more`、按书籍 ID 去重；快速切换频道/筛选不会被旧响应覆盖，加载更多失败保留已有列表。
- **清理伪能力**：移除七个没有真实数据接入的榜单入口、错误分类关键词降级、恒成功的健康检查及未使用的正文通道别名。不再用搜索结果冒充分类或榜单，也不伪造评分。
- **完整正文**：首次阅读协商移动端密钥，密钥轮换后有界刷新与重试；移除过期正文种子密钥。网页仅能预览时，不作为阅读或下载成功的替代正文。
- **移动端布局**：分类弹层分组与查找，窄屏/横屏/大字模式下筛选区域可滚动；无活动下载时停止下载管理按钮的动画。

### 数据与边界

已有书架、阅读进度、本地导入、明确下载、批注与备份继续保留；不会为了清理接口而删除本地书籍。
旧第三方代理节点不在当前运行链路中。当前首页提供官方书库，未宣称支持真实七榜、漫画或短剧。
仅处理接口正常允许返回的内容，不支持 DRM 或付费权限绕过。接口不可用时明确失败，不返回伪正文。

### 构建与验证

自动发布恢复为依赖拉取、版本校验、正式签名构建和发布，不再等待模拟器或 30 分钟关屏实验。静态分析、单元、接口与平台测试可按需手动执行，与默认发布流程分离。
接口实测区分传输成功、业务成功、有效列表和正文可解密；不会把 HTTP 200 等同于功能正常。
小样本、模拟器测试不代表所有书籍、所有网络或所有厂商设备始终可用。

下载 APK 后可使用随附 `.sha256` 文件核验完整性。
