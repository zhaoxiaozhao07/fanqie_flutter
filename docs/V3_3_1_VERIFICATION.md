# v3.3.1 图片修复与验证

版本：`3.3.1+334`；日期：2026-11-04。新建 `v3.3.1`，不覆盖 `v3.3.0`。

## 根因

上一提交 `505ccf6` 修复的是本地 EPUB 导入。首页/搜索书籍仍由移动端网关把 HTML 清洗成纯文本，图片标签在进入缓存前已经丢失；重新下载又优先复用旧 TXT 缓存。阅读器此前也只使用 EPUB 目录携带的插图。

另一个独立问题是封面仅凭文件长度大于 100 字节就认定有效，错误页面、损坏图片或不支持的格式可能被永久复用；不同页面使用不同的封面加载逻辑。

## 修复

- 移动端完整章节解密后同时提取文本和图片引用，保持原清洗器的正文及段落偏移，不把 URL、占位描述混入听书、搜索或笔记正文。
- 以正文摘要绑定版本化插图侧录文件，单独保存原文锚点、下载状态和内容寻址资源。没有插图的章节也记录版本，避免每次重复请求。
- 新下载和旧下载共用补图逻辑。旧缓存缺少图片信息时绕过所有纯文本缓存查询完整章节，正文一致才补图；不覆盖 TXT、书籍/章节 ID、阅读进度、书签或笔记。正文不同则显示拒绝修复提示。
- 阅读器先显示已缓存正文，再异步补图；支持滚动、五种分页模式、纯图片章节和点击缩放。缺文件修复后即使资源名不变，也重新解析图片，避免持续显示旧的失败状态。
- 显式下载只有正文和图片均完成才成功；坏图、缺图和过期签名可重试。EPUB 导出包含图片资源、OPF 项和原段落内的图片锚点，支持导出/重新导入回归。
- 临时图片及元数据计入缓存配额，显式下载提升至受保护的离线目录，清理临时缓存不影响它们。
- 网络图片只访问已知官方 HTTPS CDN，并逐跳验证重定向；单图 8 MB、每个书籍图片目录 128 MB、单章 2000 幅，校验尺寸和实际解码。保留签名参数；不支持的官方模板尝试兼容位图。
- 封面使用同样的解码校验、原子写入及兼容格式恢复。统一首页、详情、书架、阅读历史、下载历史和任务面板；小尺寸封面占位兼容大字。
