# v3.3.2 目录与阅读入口修复验证

2026-11-04；版本 `3.3.2+335`。保留原 `v3.3.1` 标签，新建 `v3.3.2`。

## 问题边界与上轮测试缺口

用户反馈安装 334 后，新旧书均提示无法取得目录，不能开始/继续阅读或下载。开发机与 Android 模拟器上的原代码当前仍能取得两个样本书的目录和正文，**没有在用户手机及其网络环境下复现完全相同的失败**，不能将该环境的具体原因断言为已确认。

代码可确认的故障路径：

1. 原目录仅依赖 `/page/{bookId}` 详情 HTML 中的 `window.__INITIAL_STATE__`。详情页未返回可解析数据，就返回空目录；所谓“完整书籍回退”仍重复同一个失败来源。
2. 详情和目录串行加载；网页慢/失败会拖住阅读入口。失败后阅读、下载按钮只检查旧的空列表，不实际重试。
3. 在线获取的目录没有持久保存。即使章节 TXT 尚在，本地也可能无法重建导航。
4. 下载任务面板“立即阅读”在等待目录前关闭自身，异步完成时组件已卸载，随后无法跳转。

上轮端侧插图测试预置了章节列表，未覆盖从首页书卡实际请求目录；桌面接口通过不能替代这条端侧入口验证。

## 修复范围

- 独立请求官方 `/api/reader/directory/detail?bookId=...` JSON，保留详情 HTML 作为真正独立的备用来源。
- 按 `allItemIds` 的权威顺序关联标题、卷名及章节 ID，不凭章节数伪造目录；空、损坏、重复/非法 ID 响应不写成功缓存。
- 有效在线目录原子写入受保护的 `directory.remote.json`。部分下载仅保存部分恢复目录，不截断已有完整目录；本地导入的 `directory.json` 和插图信息不覆盖。
- 已缓存完整目录支持断网立即打开；需要最新连载时可在详情页刷新，书架更新检查显式请求新目录。
- 详情元数据与目录解耦加载。失败显示具体目录错误，重试、开始/继续阅读和下载都会重新取目录，同一请求合并，成功后无需退出重进。
- 下载任务面板等目录成功后才关闭并跳转；失败不关闭面板，并显示错误。

### Android 实测不是预置目录

一个样本由真实首页书库接口返回；另一个为旧书《部族荣光》（`7069948840148732967`）。每个场景从空测试目录起步：

1. 点击实际 `BookCard`，导航到真实 `BookDetailScreen`。
2. 故障注入仅让详情 HTML 返回无法解析的页面；**目录 JSON、正文及图片仍为设备真实网络请求**。
3. 验证目录加载和“开始阅读”可用，点击后检查 `ReaderScreen` 中实际正文，并做截图检查。
4. 下载一章后，用新引擎禁用网络，验证完整目录未被截断、该章正文可读。
5. 移出书架、删除测试缓存、重新加入，再由新引擎取得完整目录和下载正文。

测试使用临时目录和测试偏好数据，不删除用户手机中的任何内容。不代表任意网络或任意书籍永不出错；若用户仍失败，新界面保留具体目录错误便于进一步定位，而不是要求继续删除数据。
