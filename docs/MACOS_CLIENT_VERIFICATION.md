### 发现并修复的问题

1. 未完成的 Swift 解码取消实现错误引用导出队列字段，导致编译失败；改为加锁的解码请求集合。
2. Darwin `iconv` 拒绝有效 GB18030 四字节补充平面字符（例如 😀）。改用 CoreFoundation 完整映射，先校验字符边界，64 KiB 读取，保留最多 3 字节跨块尾部，不替换损坏字符、不提交半文件。
3. Big5 与 GB18030 可存在有效但含义不同的字节序列，无法保证“自动”始终识别正确；保留预览与手动编码选择，不伪称通用自动识别。
4. 侧栏从展开切换到紧凑宽度时，Material 3 动画产生水平溢出；只重建导航栏，不重建业务 IndexedStack，紧凑栏采用 80 逻辑像素。
5. 长时缩放在约 229 秒发现保存段落从 169 漂移到 168。修复为重排后闲置时保留原文字符锚点，实际滚动后恢复采样；增加连续 20 次宽高变化的精确锚点回归。30 分钟复验通过：364 个采样，持续滚动及定期缩放保持原文位置，异常／缓存／RSS 趋势检查通过。
6. 内部 ad-hoc 包若开启 Hardened Runtime，Flutter 组件无共同 Team ID，会被 dyld library validation 拒绝。默认内部配置不开启 Runtime；**正式流程对所有组件使用同一 Developer ID 并明确开启 Hardened Runtime，不加入 disable-library-validation 权限。**
7. 切换 AOT 测试入口后，Flutter 增量嵌入可能导致外层签名封存旧 App.framework；内部脚本刷新外层 ad-hoc 签名并严格校验。正式包仍采用独立的嵌套正式签名流程。

### 后续：滚轮重复翻页与桌面动画节奏

- 在独立分页控件复现：一次操作发送 3 个连续滚轮信号，旧代码会提交两次翻页；持续惯性可以继续跳过多页。原因是每个信号都进入翻页入口，动画中的信号被保留为待执行请求。
- 改为首个信号立即翻页，同一串信号只延长滚动操作的活跃期，空闲 `180ms` 后接受新操作；动画中的滚轮不加入队列，动画结束后的惯性尾声也不补翻。单栏翻一页，双页翻一组（两栏连续页），不改变原有双页分页步长；大幅滚动值也不按倍数跳页。
- 优先级保持：正文子区域可以消费自己的垂直滚轮，已有选区和横向输入不触发分页；点击／键盘有意重复仍可排队，不能用全局禁用队列掩盖滚轮问题。
- **仅放慢桌面动画**：覆盖／滑动／渐变 `260ms → 320ms`，仿真 `300ms → 360ms`，仿真释放收尾同比例放慢约 20%。Android 保留 `260ms`／`300ms` 和原有拖动收尾；无动画与系统减少动态效果仍立即换页。全量测试包含原来的移动端快速点击回归，没有放宽其断言。
- 最新 analyze 无问题、494 项全量通过；新增回归覆盖 12 个间隔 `70ms` 的惯性信号跨越整个动画后仍只提交一次，并覆盖单栏和双页。真实 macOS 与新内部包结果见上方表格与产物记录。

### 2026-11-06：桌面目录、快捷操作与排版几何

- **目录桌面化**：`DesktopReaderDirectory` 为可停靠的 `304` 宽目录；窗口至少 `1060` 时占据独立左栏，窄窗口覆盖显示。章节列表惰性构建，5000 章测试只挂载视口附近条目；支持大小写不敏感的名称搜索、精确序号、分卷、倒序、定位当前章及书签／笔记入口。搜索避开 IME 未提交组合串，Enter 使用当前输入而不是迟到的防抖结果。停靠／覆盖切换的外层使用稳定键，避免销毁目录状态。
