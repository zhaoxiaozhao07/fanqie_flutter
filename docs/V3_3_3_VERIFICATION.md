# v3.3.3 章末评论恢复

日期：2026-11-05；本轮版本：`3.3.3+337`，覆盖更新 `v3.3.3`。

## 本轮根因与处理

- 分页渲染仅构建正文段落与段评，未接入滚动模式已有的章末组件。现在分页器标记真实末页并预留章末最大高度，末页重新展示“本章完”及有评论时的真实章评入口。
- 段评与章评继续独立。章评数量更新不影响分页缓存、正文字符范围或阅读锚点；翻页动画期间延后通知，点击章评不会误触翻页。
- 缓存优先的章评请求可能先返回旧的零统计，后台刷新仅更新磁盘，导致当前页一直隐藏入口。章末统计改为非阻塞的网络优先请求，服务保留离线回退。
- 纯净阅读期间跳过评论请求，退出后对已加载的当前及邻近章节补请求。无评论不显示入口；窄屏和大字模式限制入口文字宽度，正文仍完整保留。

## 上一轮历史验证：书架稳定性与阅读过渡（构建 336）

日期：2026-11-04；版本：`3.3.3+336`。

## 根因与处理

1. 主导航每次选择书架都会 `refresh()`；旧实现把 `_isLoading` 置为 true、销毁列表，再加载本地数据、补封面、检查所有连载。现在保留 IndexedStack 中的列表，仅按本地变更通知同步；切换标签不再清空重载。
2. 更新检查拿着旧 `BookshelfBook` 跨越网络等待，随后按旧下标写回；阅读、删除、添加或补封面期间返回的旧对象会回退数据甚至覆盖别的书。现在以稳定 ID 和成员版本定位，只合并更新字段，保留当前进度、时间与封面；对已经遗留的重复 ID 去重并保留较新的阅读状态，不删除书籍文件。
3. 有更新时每次检查都会保存通知，再由通知重新发起检查，形成循环。现在请求合并、自动检查冷却 30 分钟，未发生可见变化不发送刷新通知；未知章节数先建立基线，不把未读章误报为新更新。
4. 未加稳定 key 的行会在排序后复用别的书的封面状态；重复刷新又清空封面并驱逐 FileImage 缓存。现在列表/宫格提供 ID key 和索引定位，保留滚动桶；封面按文件指纹验证、按修订版缓存解码结果，未改变的文件不重复读取解码或驱逐，展示位图限制解码宽度。
5. 书架先弹加载对话框，再关闭并推入阅读页，两组动画可能叠加。现在只显示轻量页面内进度；书籍路由保留短滑入，但不使用缩放/淡入的旧页面快照。阅读器在初次滚动定位完成前遮住错误位置，不在入场期间抓旧帧，正文无插图时也不做无用刷新。
6. 20 本书的窄屏测试还暴露了标签行和宫格固定宽高比溢出。改为可约束的双标签及根据封面、字体计算格高，列表使用正确的 Material 绘制层次。

按“最近阅读”排序时，实际读过的书仍会置顶；修复的是后台旧数据回退造成的反复跳动，不取消用户选择的排序规则。
