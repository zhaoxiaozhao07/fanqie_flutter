## EPUB 插图修复与本地验证（2026-11-04）

- 根因：旧 EPUB HTML 提取器只输出文字，`img` 无子节点、SVG 被跳过，目录与阅读器都没有插图信息。
- 新导入单独保存安全的本地图片资源和段落/字符锚点，正文保持不变；支持 URI 转义、去重、SVG 包裹位图、目录锚点及纯图片章节。
- 滚动与五种分页模式都渲染插图、支持放大；图片页位置可保存。缺失、损坏、加密、危险引用或不支持的资源显示提示，不伪造正文。
- 旧版 v2 EPUB 重选同一源文件可补齐插图；先比较 canonical 正文，再校验原文件哈希，只追加图片并更新目录，不覆盖原正文、书 ID、原文字章 ID、进度、书签或笔记。正文有变化则拒绝升级。
- 资源路径、单张大小、总量、数量及像素尺寸受限；SVG 拒绝脚本、外部引用和不安全样式，内部位图经过校验后内嵌。
- 添加 `flutter_svg`，将 XML 依赖范围调整至 `^7.0.1` 以满足 SVG 编译器明确的上限约束；应用未使用 XML 7.1 新增 API，已有导入/备份测试一并回归。

## 修复范围

- 官方分类源：`/api/author/book/category_list/v0/`，按频道获取并保存上一次成功的元数据，不再使用两套手写分类表。
- 书库：`/api/author/library/book_list/v0/`，频道映射为全部 `-1`、男频 `1`、女频 `0`；字数五档为 `0–4`；状态和排序与官方客户端协议对齐。
- 分类组名、名称、ID、数量均来自响应。分类可查找；频道变化清空不兼容选择，刷新移除已失效分类选择。
- 成功空页、业务失败和传输失败分开处理；分页遵循 `has_more`，去重并防止迟到响应覆盖新筛选结果。
- 移除关键词伪榜单、分类关键词降级、伪健康检查、正文通道别名、未使用的批量正文接口和旧匿名 Cookie 资产。
- 正文密钥首次协商、并发握手合并、密钥轮换后有界重试；校验响应、密钥长度、填充及 UTF-8。拒绝网页预览回退和损坏正文。
- 不删除已有书架、进度、本地导入、明确下载或批注。旧预览占位内容不会作为成功正文使用。
- 修复无下载时仍运行的按钮动画；窄屏、横屏和大字布局验证。
