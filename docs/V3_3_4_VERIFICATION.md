# v3.3.4 完整章节讨论流验证

日期：2026-11-05；版本：`3.3.4+339`；新标签：`v3.3.4`。

本文件记录首发构建 `339` 的历史验证；帖子回复覆盖更新 `340` 见 [本轮验证](POST_REPLIES_VERIFICATION.md)。

## 根因与修复

- 旧 `/reading/ugc/novel_comment/item/v/` 只返回章评，不包含新版书圈讨论。示例书 `7322304923511557182` 第 1521 章 `7561721731426026009` 的 6 条讨论实际为 1 条章评和 5 条帖子，不能只通过修改缓存或翻页补齐。
- 自动从 `/reading/ugc/forum/desc/v1/` 解析该书的书圈 ID，再请求 `/novel/articleapi/feed/v1`（source=2、channel=7）。书圈 ID 按书缓存 6 小时，合并并发查询，不缓存失败结果。新版版本参数仅用于讨论接口，正文、密钥协商、段评和书评协议不变。
- 混合流已包含章评，不再与旧接口重复合并。解析章评、帖子和作者话题，按类型与 ID 去重；保留富文本正文、图片、@ 提及、作者信息和统计。不执行富文本 HTML；不支持的附件或类型明确提示。
- 上游 `count=1` 探测会推进帖子扫描游标却丢弃部分帖子，实测小页分页只能取得该章的 3/6 条。新版流将小页请求提升至正常 `count=20`，章末统计仍只读取总数；正常列表保持按需分页，不一次性下载整章。
- 原样透传 JSON 游标，不将其解析成整数或本地列表长度。旧接口的数字游标仅续载旧来源；新版下一页失败不切换旧来源，不返回第一页缓存。短页自动续载、分页重试、刷新代次与空页保护保留。
- 新讨论缓存使用独立 `discussion_v2` 文件，按请求大小隔离。旧版即使写有 `total=1 / hasMore=false` 也不视为完整在线命中。降级返回旧章评时不覆盖已有新版缓存；离线或旧版来源显示提示，旧阅读数据和缓存不删除。

真实网络验证可复现：

```sh

  --dart-define=FANQIE_LIVE_API=true --reporter expanded
```

真实验证只覆盖上述样本及当时官方返回，不承诺所有书籍、网络或未来接口版本均可用。未缓存的后续页仍需联网。

## 边界

普通章评子回复维持原接口。书圈帖子及话题的子回复暂不支持展开，面板显示明确说明，不将帖子 ID 错发给章评回复接口。视频等不支持的帖子附件以占位提示呈现。
