# 阅读体验增强计划 V2

> 制定日期：2026-11-02  
> 代码基线：`936a980`，应用版本 `3.1.1+311`  
> 范围：以现有 Android 阅读器为主；本轮只制定计划，不实现业务功能。  
> 核查方式：静态检查代码与已有测试。本文件中的性能数字是建议验收目标，不是实测结果。

## 一、总体判断

下一轮不宜继续堆叠翻页动画，而应围绕四个目标投入：

1. **不中断**：弱网、切后台、切章、听书切换时，不丢位置、不漏内容。
2. **更舒适**：夜间亮度、排版预设、低干扰模式和无障碍体验。
3. **更可控**：查找正文、跳转后返回、看清离线可读范围。
4. **更可靠**：本地文件正确解析，书签笔记可恢复，平台功能真正闭环。

沿用上一版计划中已经落地的基础，不将已有功能重新列为“新增”。保留[上一版计划](/Users/xiuxiu/CodeProgram/fanqie_flutter/docs/NOVEL_READING_ENHANCEMENT_PLAN.md)作为历史规划。

## 四、详细实施方案

### E1｜阅读连续性与进度一致性

**实施内容**

- 复用现有 `ReadingPosition`，让书架续读、历史续读、目录跳转、书签定位、看书/听书切换走同一个位置入口。
- 为持久化快照加入版本与更新时间；明确写入顺序，避免章节摘要和原文位置分别更新后不一致。
- 续读优先按章节 ID 定位；目录插章、删章时，按上下文或相邻章节降级并提示，不能仅用旧序号跳到另一章。
- 覆盖横竖屏、字体加载失败、大小字切换、弹窗交互、系统回收后重开等场景。
- 定义前台周期保存与生命周期保存边界。突发进程终止恢复到最后成功持久化的快照，不承诺恢复尚未落盘的最后一帧。

**验收**

- 不改正文的重排操作后，分页模式仍包含原锚点字符；滚动模式目标行偏差不超过一行。
- 连续切换排版/模式 100 次，无跨章误跳、空白页或重复覆盖新进度。
- 重启后恢复已提交快照；目录变动不会无提示地恢复到错误章节。

### E2｜弱网与离线体验

**实施内容**

- 在已有预取机制上升级调度，不再另建一套缓存：当前主动请求优先，其次相邻正文，最后评论和远端预取。
- 暴露“本地可读至第 N 章”“正在缓存”“缓存失败，可重试”等非阻断状态；离线范围以磁盘实际完整文件为准。
- 提供“省流量 / 标准 / 通勤”策略，支持仅 Wi-Fi 自动预取；网络状态只是提示依据，请求结果才是可用性的依据。
- 跳章或退出时撤销过期排队任务；不能中止的在途请求也必须隔离迟到结果。
- 对临时失败做有上限的退避重试；区分网络错误、内容不可用、解析错误和磁盘写入失败，保留当前正文。
- 将临时阅读缓存、用户显式下载、本地导入三类内容区分管理。仅临时缓存按容量和 LRU 淘汰，不能误删已导入书或用户要求保留的离线书。
- 评论优先显示可用缓存，后台更新；关闭全部评论展示后，不再自动拉取评论。

**验收**

- 断网连续读完已标记缓存的章节；未缓存章节说明原因并提供重试，不显示空白替代页。
- 同章的主动请求与预取请求合并；退出后迟到请求不改变新阅读会话。
- 清理缓存不影响本地书、明确保留的离线书、进度和笔记。

### E3｜听书可靠性与平台闭环

**实施内容**

- 给播放会话、章节和切片分配稳定标识；网络请求及原生回调携带标识，忽略上一会话的迟到事件。
- 修正“异常等同播放完成”的策略：失败时有限重试、明确降级或暂停提示，不默默跳过正文。
- 暂停要覆盖缓冲中状态；确认实际播放引擎后再执行恢复，避免网络语音降级原生后走错恢复路径。
- 补齐 Android 媒体会话、通知栏/锁屏操作、音频焦点和耳机断开处理；后台播放采用明确的服务生命周期，不依赖阅读页面存活。
- 先验证 Android 目标版本的前台服务、通知权限和音频要求，再确定原生或成熟 Flutter 音频方案。
- 睡眠定时跨章节持续有效；渐进淡出只影响本应用音频，停止后复位。原生 TTS 不支持精确句内恢复时明确退回当前句/切片。
- 将语音服务密钥迁移到平台安全存储；日志、笔记备份不包含密钥或完整请求正文。

**验收**

- 锁屏播放 30 分钟，暂停/继续、上一段/下一段、跨章与定时停止均可操作。
- 来电或其他音频抢占、耳机断开后按约定暂停，不突然外放；恢复策略可预测。
- 快速切书、反复暂停、网络超时与重复完成回调，不串音、不双重推进切片。
- 必须真机验证；返回 `null` 的 MethodChannel mock 不能证明平台功能可用。

### E4｜夜间舒适度与排版预设

**实施内容**

- 设置分为“常用”和“高级”：常用提供字号、主题、亮度和预设，高级保留已有字距、段距、边距等参数。
- 新增“紧凑 / 纸书 / 大字”预设，支持保存个人预设；默认全局，可单书覆盖，并提供恢复默认。
- 主题增加“跟随系统 / 手动 / 定时夜间”，临时手动调整优先级明确。
- 增加阅读窗口独立亮度和“跟随系统”；退出阅读后还原窗口设置，不修改系统全局亮度。
- 检查正文、次要文字、选中态、高亮及弹窗的颜色对比；夜间打开设置和目录不能闪白。
- 自定义字体导入作为后续可选项：限制格式、大小，校验加载失败与授权提示；不阻塞本轮舒适度交付。

**验收**

- 常用排版调整不超过两层操作；预设切换继续满足 E1 保位标准。
- 深色主题覆盖目录、批注、评论、加载、错误态和听书面板。
- 正常字号正文和可操作标签以对比度不低于 4.5:1 为目标，不将某种背景色宣传为医学“护眼”。

### E5｜正文搜索与往返导航

**实施内容**

- 保留现有章节名称搜索，新增“本章正文”和“已缓存正文”搜索。
- 结果展示章节、匹配片段和高亮；进入后按原文字符范围定位，不依赖当前页码。
- 搜索范围明确标注，例如“已搜索本地 120/500 章”。不为搜索自动下载整本书，不将局部结果描述为全书结果。
- 建立有界跳转历史：目录、搜索、书签等显式跳转后，提供“一键返回原阅读位置”；普通翻页不产生历史。
- 尚未确认的进度预览不写入正式续读位置，防止拖动预览覆盖正常阅读进度。
- 初期按章分批检索并支持取消；数据规模证明确有必要后再引入持久化索引，避免一次加载全书。

**验收**

- 同章重复词句定位到正确匹配项；分页和滚动模式均可返回精确原位置。
- 搜索期间仍可操作，取消后旧结果不会覆盖新关键词结果。
- 离线搜索不发起正文下载；结果清楚说明搜索覆盖范围。

### E6｜本地书籍兼容性

**实施内容**

- TXT 支持 BOM 检测、UTF-8、UTF-16、GB18030 等常见编码；无法确定时提供编码预览选择，不再以 Latin-1 兜底呈现中文乱码。
- 目录识别增加预览和规则选择，处理序言、番外、英文章节及无标题长文；保留源文件供重新解析。
- EPUB 按 `container.xml → OPF manifest/spine` 获取阅读顺序，结合 EPUB 2 NCX / EPUB 3 nav 获取目录层级；用结构化解析替代仅靠正则去标签。
- 用内容摘要或稳定 UUID 识别本地书籍，区别同名不同书并识别重复导入；对旧书籍、进度和笔记保留标识映射。
- 导入到临时目录，校验通过后再提交并加入书架；异常不生成“解析成功但没有正文”的占位章节。
- 大文件解析分批或放到 isolate，支持进度与取消；限制解压总量和文件数量，校验归档路径，避免异常压缩包耗尽资源。
- 不支持 DRM 绕过；遇到加密或不支持的文件明确说明。

**验收**

- 编码样本、文件名顺序不同于 spine 的 EPUB、多级目录、同名不同书均正确处理。
- 导入失败或取消不留下半本书；重复导入不会静默覆盖已有笔记。
- 大文件导入中界面可交互，正文顺序和章节内容通过固定样本校验。

### E7｜沉浸交互与无障碍

**实施内容**

- 新增“一键纯净阅读”：同时隐藏段评、章末讨论和非必要状态信息，仍保留可发现的菜单入口；恢复后回到原设置。
- 在已有均衡/右手热区上增加左手模式和热区示意；选中文字、拖动选区、打开弹窗时统一禁用翻页热区。
- 提供触感反馈开关、状态栏项目开关，以及屏幕常亮策略；休息提示默认关闭，不强制打断。
- 在现有字号缩放和减少动画支持上，补齐 TalkBack 标签、焦点顺序、翻页语义操作及无障碍提示。
- 段评气泡保持视觉轻量，但有效触摸区域与邻近文字选区需有明确冲突规则。

**验收**

- 左右手操作、气泡点击、长按选择、自动滚屏、音量键和弹窗组合无误触回归。
- 1.0 / 1.3 / 1.6 / 2.0 字体缩放下主路径可用；不以裁切正文解决溢出。
- 核心控件触摸目标原则上至少 48dp；TalkBack 可完成续读、翻页、开目录和关闭面板。

### E8｜精确批注与数据备份

**实施内容**

- 书签支持同章多处位置；笔记保存稳定章节 ID、选区起止偏移、原文摘录及上下文校验信息。
- 原文更新后先精确匹配，再用上下文重定位；多义或匹配失败时标记“待重新定位”，不自动关联错误段落。
- 增加笔记编辑、颜色/标签、按书与关键词筛选，以及 Markdown / JSON 导出。
- 提供本地备份与恢复，覆盖书架、进度、偏好和批注；正文文件作为用户显式选择的独立备份项。
- 恢复前显示摘要和冲突选项，支持版本校验、回滚和重复导入去重。首版不引入账号体系或云同步。

**验收**

- 同一段落出现两次相同短语时，只标记用户选择的那一处。
- 旧数据迁移与备份恢复后锚点可定位；未知版本或损坏备份不覆盖当前数据。
- 导出不包含语音密钥、身份凭据或其他与备份目标无关的数据。

### E9｜轻量阅读辅助

**实施内容**

- 可选显示“本章预计剩余 X 分钟”，基于有效阅读速度逐步校准；未形成样本时显示保守估计或不显示。
- 分开统计看书与听书，扣除后台时间和长时间无交互停留；设置中可关闭并删除统计。
- 最近阅读入口可展示上次阅读片段作为回忆提示，不默认生成或上传剧情摘要。
- 不做强制打卡、排行榜、阅读时长弹窗或会破坏沉浸感的成就系统。

**验收**

- 切后台、屏幕关闭不会虚增看书时长；听书单独统计。
- 未知章节长度时不把章节数量占比包装为精确全书字数进度。
- 所有统计默认本地保存，禁用后不影响续读。

## 五、技术实施约束

### 5.1 渐进拆分，不重写阅读器

按功能改动逐步形成以下职责：

- `ReaderSessionController`：当前章节、原文锚点、跳转历史、会话生命周期。
- `ReaderSettings` / `ReaderSettingsRepository`：全局与单书设置、预设、版本迁移。
- `ChapterRepository` / `PrefetchScheduler`：正文来源、缓存状态、请求去重与优先级。
- `ReaderSearchService`：本章和本地正文检索。
- `TtsPlaybackSession`：实际播放引擎、切片状态、原文映射和平台回调。

继续复用现有[分页引擎](/Users/xiuxiu/CodeProgram/fanqie_flutter/lib/services/reader_pagination.dart)、[翻页组件](/Users/xiuxiu/CodeProgram/fanqie_flutter/lib/widgets/reader_page_view.dart)和[位置服务](/Users/xiuxiu/CodeProgram/fanqie_flutter/lib/services/reader_position_service.dart)。先补接口测试再抽离，不同时重写 UI、分页和数据层。

### 5.2 数据与资源边界

- 原文文本与展示变换分离；笔记、搜索、分页和 TTS 使用同一套偏移约定，避免缩进、清洗或繁简转换破坏锚点。
- 明确 Dart 字符偏移约定，并在截断/选区边界测试 emoji、代理对和组合字符。
- 小型偏好可继续使用 SharedPreferences；高频进度和批注需要可靠的串行/原子持久化。是否引入 SQLite，根据数据量与事务需求决定，不为规划而预先迁库。
- 内容解析、搜索等适合后台计算的任务可放入 isolate；依赖 Flutter 文本布局的 `TextPainter` 不直接搬到普通 isolate。
- 性能日志不记录正文、笔记和密钥；联网评论、网络语音均尊重用户开关。

### 性能目标

先在 S0 固定低端/中端 Android 设备、测试书籍和脚本，再校准下列候选门槛；使用 profile/release，不以 debug 构建评价帧率。

| 指标 | 建议目标与口径 |
| --- | --- |
| 缓存续读打开 | App 已运行、章节在磁盘，点击续读至正文可交互 P95 ≤ 500ms；冷启动单独统计 |
| 缓存跨章 | 相邻内容已缓存时，不计设计内动画时长的额外等待 P95 ≤ 150ms |
| 翻页/滚动流畅度 | 60Hz 下超帧预算比例 < 1%；120Hz 按 8.3ms 单独评估，分别看 UI 与 raster 耗时 |
| 长读资源 | 连续 100 章后，内存与图像缓存无随章节数持续增长；预热后尾段内存稳定在基线约定范围 |
| 正文查找 | 基准设备与固定本地语料中，首批结果 P95 ≤ 500ms；完整检索可取消，界面不中断 |
| 弱网失败 | 保留已显示正文；请求有超时和重试上限，无永久 loading、无隐式跳过章节 |

每个阶段结束都需通过静态分析、适用的自动化测试和对应真机场景；外部接口测试与可复现的本地测试分开记录。文档仅描述已验收能力，避免再次出现“已有 Dart 接口即宣称完整支持”的情况。

## 八、暂缓事项

- 更多仿真特效、纸张纹理、翻页音效：投入收益低，可能增加干扰和耗电。
- 云端账号与多设备同步：涉及身份、冲突、隐私和长期服务维护，先验证本地备份。
- AI 剧情总结、角色关系图：存在剧透、内容外传、费用与准确性问题，不放进阅读主路径。
- 社区发帖、视频、漫画等扩展：偏离纯小说阅读定位。
- 桌面与 iOS 完整体验：当前仓库的平台实现以 Android 为主，另行估算，不默认获得同等支持。

**推荐起点：先做 S0–S1。优先保证“打开接着读、翻章不中断”，再补齐听书平台闭环，随后交付夜间亮度、正文搜索和一键返回。**
