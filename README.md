## 已有阅读体验

### 阅读连续性
- 原文锚点保存章节 ID、段落与字符位置，字号、字体、横竖屏和阅读模式变化后继续定位原文。
- 续读入口统一使用版本化快照；目录变化时明确提示降级定位。
- 目录、搜索、书签和笔记跳转支持一键返回，加载失败或取消时保留当前内容。

### 排版、夜间与操作
- 上下滚动、左右分页；覆盖、仿真、滑动、渐变与无动画。
- 系统字体及内置宋体/楷体，字号、行距、字距、段距、缩进和页边距设置。
- 紧凑/纸书/大字预设、个人预设、全局设置与单书覆盖。
- 手动、跟随系统与定时夜间主题；独立阅读窗口亮度，退出阅读后恢复。
- 纯净阅读、左右手点击热区、音量键、自动滚屏、可选触感与默认关闭的休息提醒。
- 大字布局、翻页语义操作和系统减少动画适配。行内段评保持紧凑视觉，亦可通过段落菜单访问。

### 离线与查找
- 正文请求去重，邻近预取，省流量/标准/通勤策略与仅 Wi-Fi 自动预取。
- 显示磁盘实际可读范围、缓存占用与失败重试。
- 临时阅读缓存独立限额清理，不自动删除明确下载、本地导入、进度或批注。
- 支持本章与已缓存正文搜索，显示覆盖范围，结果按原文字符范围定位；不会为了搜索下载全书。

### 听书
- Android 系统语音与用户配置的兼容语音服务。
- 会话/切片标识隔离迟到事件，错误暂停或明确降级，不静默跳过正文。
- 前台媒体服务、锁屏与通知栏播控、音频焦点、耳机断开暂停。
- 跨章节定时停止、整章结束停止、音量淡出；音频缓存只保留邻近片段。
- 离开阅读页面可以继续听书；主动翻页、滚动或跳转停止本书听书，可从新位置开播。
- 网络语音会将当前与后续两段正文发送给所配置的服务。密钥使用 Android Keystore 保存，不加入阅读备份。

### 本地 TXT / EPUB
- 使用系统文件选择器，先检查编码/目录/正文预览，再确认导入。
- Android 支持 UTF-8、UTF-16、GB18030/GBK、Big5；可手动选择编码和章节识别规则。
- EPUB 按 OPF spine 阅读顺序，结合 EPUB 2 NCX / EPUB 3 nav 目录和锚点拆分。
- 支持正文 PNG/JPEG/GIF/WebP/BMP 与安全 SVG；按宽高比排版并可放大。图片限单张 8 MB、总量 128 MB、2000 幅；不加载远程图片、脚本或 DRM 加密插图。
- 同名不同内容互不覆盖；相同内容去重；保留源文件。安全匹配旧版书籍时保留原 ID 和阅读数据。
- 流式处理、后台解析、取消与临时目录提交；不生成“成功但没有正文”的占位章节。
- 输入文件上限 128 MB；拒绝危险路径、链接、超限压缩资源、损坏数据与加密正文，不支持 DRM 绕过。

### 书签、笔记与备份
- 同章多书签，精确选区划线、颜色、标签、笔记编辑与搜索。
- 章节内容指纹与引用上下文辅助定位；歧义位置明确提示，不猜测跳转。
- Markdown/JSON 笔记导出；本地阅读数据备份，可另选包含书籍文件。
- 恢复提供合并/替换，先校验再应用；事务日志支持失败回滚和启动恢复。
- 备份不包含语音密钥。备份和导出可能包含私人阅读信息，请妥善保管。

### 轻量阅读辅助
- 默认关闭的本地阅读统计，区分看书与听书，过滤后台和长时间无交互停留。
- 可关闭并清空统计，不影响书籍与阅读进度。
- 启用后显示本章剩余时间估计；最近阅读可显示上次片段，不生成或上传 AI 剧情摘要。

其他已有功能包括：书架、阅读历史、连载更新检查、TXT/EPUB 下载、封面缓存及段评/书评浏览。

## 发布

版本号来自 `pubspec.yaml`，发布标签必须与其一致。发布 workflow 恢复为单个快速构建任务：

1. 版本校验与依赖拉取。
2. 使用配置的正式签名密钥构建 APK。
3. 生成 SHA-256，上传产物；标签或手动发布时更新 GitHub Release。

静态分析、单元测试、真实接口测试、模拟器与 30 分钟关屏实验均不再作为默认构建的前置条件，仍可按上文命令手动运行。

发布需要仓库签名 secrets：`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_PASSWORD`、`KEY_ALIAS`。不会将无签名配置的临时调试签名作为正式发布回退。

## 已知边界

- 第三方内容/评论接口可能变化或不可用；断网只能阅读确已缓存的内容。
- 系统语音需要设备安装可用的中文语音引擎；原生暂停恢复以当前切片为单位。
- 阅读时长和剩余时间是依据交互与进度的估计，不代表注意力或精确阅读速度。
- 模拟器和自动化验证不等同于所有厂商系统、真实中文音色听感或低端真机性能测量。
- 本轮不包含账号云同步、AI 剧情总结、其他内容形态或完整 iOS/桌面端适配。
