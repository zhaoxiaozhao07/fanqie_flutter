# 🍅 番茄Reader (Fanqie Novel Reader)

一款基于 **Flutter** 开发的高颜值、高性能第三方番茄小说阅读与下载客户端。  
**纯 Dart 原生内置完整后端服务引擎**，彻底免除部署外部服务器或配置任何后端地址，开箱即用。

## 📖 核心特性与架构升级 (v3.1.0 - 纯小说阅读全维增强版)

### 💬 1. 官方原生段评、书评与楼中楼互动系统 (新)
- **官方移动端直连 (无需登录即可浏览)**：直连官方评论系统，原生调用 `idea/list` 段评统计、`comment/list` 列表及 `reply/list` 回复接口，支持智能热门与最新排序；
- **正文段落气泡与原文引用**：
  - 正文被评论段落末尾优雅展示半透明胶囊气泡（`💬 N`），支持设置中随时开启/关闭；
  - 点击气泡滑出半屏段评抽屉，顶部保留被评段落原文卡片，支持**定位原文**并伴随平滑高亮聚焦；
- **多媒体与勋章解析**：
  - **表情与图片**：自动将 HEIC 格式及官方 CDN 签名图重写为公共 WebP 高清直链，支持点击放大查看原图；
  - **头衔与身份识别**：准确识别作者勋章、官方认证、小编以及特色专属头衔；
- **二级楼中楼回复**：支持展开/收起楼中楼回复，展示层级讨论、点赞数与回复者信息；
- **全书书评与离线自愈**：
  - 书籍详情页新增读者书评精选区块与完整评价抽屉；
  - **离线阅读完美适配**：对于已下载离线的图书，在线时自动更新段评，断网离线时自动无缝回退读取本地段评缓存，断网也能看热评！

### 🚀 2. 纯 Dart 内置后端引擎 (Zero-Server Architecture)
- **完全内置运行**：完整移植并内置原本外部独立的 `fanqie-backend` 服务，免除部署或连接任何外部 Python/FastAPI 后端，不再提供任何后端地址配置项，纯本地自包含运行。
- **汉字反爬字体解密**：原生内置书库筛选与正文阅览全套 362 个 PUA 汉字解密映射字典，毫秒级内存解码，完整还原标准汉字。
- **全量多维筛选与书库**：直连官方书库 API，对齐分类、字数、连载状态、男频/女频与排序的多维复合检索，并具备榜单关键词动态降级自愈能力。
- **书籍详情与智能分卷**：通过多级正则与状态机精准提取分卷目录与章节元数据。

### 🔓 3. 移动端专属通道与无锁全量正文 (突破 Web 端 200 字限制)
- **移动端协议纯原生逆向**：纯 Dart 实现了字节跳动移动端双重安全签名与数据解密体系，包括：
  - **SM3 哈希** 与 **Simon-64/128** 轻量级分组密码（72 轮密钥扩展预编译）；
  - **Ladon** 34 轮 ARX 哈希表扩散算法；
  - **Protobuf 序列化** 与 **Argus-551** 安全签名协议；
  - **动态 AES 密钥协商 (`registerkey`)** 与 **AES-128-CBC 密文解密 + Gzip 流式解压**。
- **彻底消除预览锁章限制**：彻底突破番茄官方 Web 端中后段章节出现的 `[提示：本章为番茄APP端专享/锁章章节，当前官方Web端仅提供试读预览]` 截断，获取 2,000 ~ 5,000+ 字无锁完整正文。

### ⚡ 4. 高性能异步并发下载
- **长连接管道化**：维护持久化 HTTP/1.1 单例连接池（`maxConnectionsPerHost: 32`），复用活跃连接，彻底消除频繁 TCP 与 TLS 握手 RTT 开销。
- **解除限速与并发流水线**：内置引擎直接控制 12 并发 Worker，解除前端人为批次停顿，单章毫秒级响应。
- **非阻塞后台任务与即时保存**：点击下载即时返回，在后台持续作业，主界面右上角常驻动态下载指示器；下载完成直接流式装配 TXT 与带有封面和目录的规范 EPUB 电子书，彻底根治卡在最后章节的问题。

### 📚 5. 极致顺滑的阅读器体验
- **双阅读模式自由切换**：
  - **双向无缝连续无限滚屏**：在传统无限下拉基础上，真正支持往上滑动平滑追加上一章，并引入精准的高度差值补偿（`jumpTo(oldOffset + deltaHeight)`），当前阅读视口内容纹丝不动；
  - **左右仿真翻页模式 (PageView)**：支持左右滑动翻页与屏幕两侧点击热区翻页（左侧 28% 前翻、右侧 28% 后翻、中间 44% 呼出菜单），满足传统纸质书与单手翻页习惯；
  - **满帧长文架构**：50px 节流探测、局部邻近章节探测、`RepaintBoundary` 绘制图层隔离，彻底消除连续阅读十几章后的掉帧与卡顿；
- **精细排版定制与多字体**：
  - 支持**系统默认、典雅宋体、温润楷体、现代黑体**等正文字体自由切换；
  - 支持**首行缩进（2字符开关）、字间距（紧凑/适中/宽松）、段落间距（小/中/大）与页边距**四维复合微调，排版更具呼吸感与纸书质感；
- **沉浸式自动阅读 / 自动平缓滚屏 (Auto-Scroll)**：
  - 提供专属自动滚屏模式，支持 15~100 px/s 速度无级调节；
  - 悬浮胶囊控制条（调速、暂停、退出），点击正文任意位置随时暂停/继续，解放双手；
- **目录体验飞跃与分卷折叠**：
  - 支持**正序 / 倒序一键切换**，追更几千章长篇小说迅速定位最新章节；
  - 原生支持**按卷折叠 / 展开视图**，当前阅读章节自动居中高亮并展开所在卷；
- **后续 3~5 章静默预加载流水线 (Silent Pre-fetching)**：
  - 读者阅读到当前章节后半段时，后台并发流水线**静默预拉取并本地持久化后续 3~5 章的正文与段评数据**，彻底消除翻页骨架屏与 Loading，做到进电梯、地铁断网环境下的“绝对零等待”无缝阅读；
- **书签、划线高亮与阅读笔记系统**：
  - **顶栏一键书签**：随时记录精彩章节与视口位置；
  - **段落长按互动**：长按任意正文段落弹出快捷操作气泡，支持**荧光高亮划线、写读后感悟笔记、一键复制文本**；
  - **三合一管理抽屉**：目录抽屉无缝集成「目录 / 书签 / 笔记」选项卡，支持一键定位瞬移至对应章节段落并支持滑动删除。

### 🎙️ 6. 智能流式预拉取 TTS 听书系统
- **双引擎支持**：支持 **Android 系统原生 TTS** 与 **OpenAI 兼容语音接口 (`/v1/audio/speech`)**；
- **音色自由自定义**：OpenAI 兼容模式下不仅内置官方经典音色，更支持自由输入任何自定义或第三方模型音色（如 `zh-CN-XiaoxiaoNeural`, `nova`, `custom-voice` 等）；
- **智能短句分块与双缓冲预拉取流水线**：
  - 按句末标点自动切分为 80~200 字的高效自然句块；
  - 播放切片 N 时，后台并发管道**提前异步拉取并缓存切片 N+1 与 N+2**，播完 0 毫秒无缝切入，彻底杜绝切句停顿与大段超长请求超时；
- **读完本章后自动停止 (新)**：睡眠定时器新增「读完本章后停止」选项，听完剧情自然关停；定时结束前 1 分钟音量平滑淡出，不惊扰睡眠；
- **锁屏与媒体中心播控联动 (新)**：实时同步当前书名与朗读章节到系统锁屏媒体控制台，支持耳机线控双击切换与暂停/继续；
- **Word 经典温润荧光高亮**：根据当前阅读主题自动适配同色系低饱和度温和底色，绝不刺眼，自然保留段落行气；
- **当前视口首句直接开播**：点击听书根据读者视线在屏幕上的垂直坐标，从当前屏幕顶部第一句话开口朗读；
- **智能字幕平滑滚屏跟随**：高亮文字始终平滑保持在屏幕黄金视线舒适区。

### 🖼️ 7. 书架与连载追更体系
- **连载书籍更新检测与更新红点 (Update Watcher - 新)**：
  - 书架下拉刷新时后台自动探测连载书籍最新章节数；
  - 发现新更章节在封面右上角展示醒目「更新」红点徽标，点击进入阅读或读到最新章节自动消除；
- **本地 TXT / EPUB 小说导入与纯本地阅读 (新)**：
  - 支持从本机导入任意外部 `.txt` 或 `.epub` 电子书文件；
  - TXT 智能章节识别切分（支持经典“第X章”正则与无标题长文自愈切块），EPUB 自动解压提取章节与封面；
  - 导入后自动并入书架，直接享受双模式阅读、排版、书签与 TTS 听书；
- **实体书黄金长宽比 (1 : 1.42)**：三列宫格彻底消除矮胖正方形，封面与文字容器高度完全解耦恒定，全屏书籍整齐划一，大小绝对一致；
- **操作精准分区**：点击书本封面直接进入阅读秒开；点击书名/作者文字区域进入书籍详情页；
- **三级自愈封面体系**：
  1. 本地永久离线磁盘缓存（`${docDir}/offline_books/${bookId}/cover.jpg`）；
  2. 已下载 EPUB 内部封面自动解压提取；
  3. 书架与下载记录双索引跨源互补；
  4. 后台搜索接口静默补全最新封面。

## 🏗️ 核心架构与协议原理

### 1. 移动端安全通信与解密链路
```
[书籍 itemId] 
      │
      ▼
[移动端网关: /reading/reader/full/v]
      │
      ├──> [Argus-551 协议封装] ──> Protobuf Bean 序列化 ──> Simon-64/128 加密 ──> SM3 哈希校验
      ├──> [Ladon 34 轮扩散] ──> ARX 哈希表动态置换
      └──> [动态 AES 密钥协商] ──> /reading/crypt/registerkey (AES-128-CBC 交互)
                                            │
                                            ▼
                             [获取加密正文密文]
                                            │
                                            ▼
                 [AES-128-CBC 解密] ──> [Gzip 压缩流解压] ──> [HTML 标题/段落清洗]
                                            │
                                            ▼
                           [突破锁章限制的万字完整正文]
```

### 2. TTS 双缓冲滑动窗口流水线
```
[当前朗读: 切片 N] ──> (正在通过本地音频播放器平滑输出)
        │
        └──> [后台并发管道] ──> 提前异步请求 OpenAI 接口拉取并缓存 [切片 N+1] 与 [切片 N+2]
                                      │
[切片 N 播完触发 onAudioComplete] <───┘
        │
        └──> [切片 N+1] 音频已在本地完全就绪，0 毫秒无缝切入播放！
        │
        └──> [后台并发管道] 立即异步预拉取 [切片 N+3]
```
