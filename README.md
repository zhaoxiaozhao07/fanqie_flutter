# 番茄小说 Flutter 客户端 (番茄Reader)

一款基于 Flutter 开发的番茄小说第三方客户端，**已内置完整后端引擎**，支持小说搜索、多维分类浏览、在线阅读、后台高速下载等功能。

## 核心特性

- **内置后端引擎** - 完全无需单独部署或运行外部 Python 后端，开箱即用，不再需要配置任何后端服务器地址
- **字体反爬解密** - 内置阅读页与书库页全量汉字解密字典，完整还原标准中文文本
- **无限制高速下载** - 下载直接调用内置后端并发接口，前端不设人为限速或批次延迟，支持秒级直出与断点续传
- **后台异步下载** - 采用非阻塞后台下载任务架构，下载时可自由阅读、浏览其他书籍或切换页面，底部实时展示下载进度与管理控件
- **榜单浏览** - 支持巅峰榜、出版榜、热搜榜、黑马榜、爆更榜、推荐榜、完结榜
- **全量多维筛选** - 对齐番茄书库官方分类、字数、状态、男频/女频与排序多维筛选
- **书架与阅读器** - 支持加入书架、进度记忆、无限下拉阅读与离线缓存
- **格式导出** - 支持直接保存为 TXT 与标准 EPUB 电子书

## 技术栈

- **Flutter 3.10+** - 跨平台 UI 框架
- **Dart** - 开发语言
- **cached_network_image** - 图片缓存
- **archive** - EPUB 电子书打包

## 构建

### 环境要求

- Flutter SDK 3.10.4+
- Dart SDK 3.0+
- Android SDK (Android 开发)

### 编译运行

```bash
# 获取依赖
flutter pub get

# 运行调试版本
flutter run

# 构建 Release APK
flutter build apk --release
```
